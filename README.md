# FlowTask – İşletmeler İçin Görev Otomasyonu

FlowTask, işletmelerin tekrarlayan görevlerini, müşteri taleplerini ve iş akışlarını daha düzenli yönetmesine yardımcı olmak amacıyla hazırlanmış kurgusal bir teknoloji hizmeti landing page prototipidir.

Proje, ENTEKSİS değerlendirme çalışması kapsamında geliştirilmiştir.

## Canlı Uygulama

https://enteksis-task.onrender.com

## Teknolojiler

- HTML5
- CSS3
- JavaScript
- Python
- Flask
- PostgreSQL
- Supabase
- Render
- unittest
- Git / GitHub
